# Мила — дашборд статистики (облачная версия)

Дашборд часов и выплат сотрудников. Данные берутся из Google-таблицы
по ссылке (экспорт в xlsx), поэтому при изменении таблицы дашборд
обновляется сам — ничего загружать не нужно.

## Файлы

- `app.py` — приложение Streamlit
- `requirements.txt` — зависимости
- `.streamlit/config.toml` — конфигурация Streamlit

## Деплой на Streamlit Community Cloud (бесплатно)

1. Создайте репозиторий на GitHub:
   - зайдите на https://github.com → **New repository**,
   - имя: `mila-dashboard`, `Public`, создать;
   - на странице репозитория: **Add file → Upload files**,
     перетащите сюда `app.py`, `requirements.txt` и папку `.streamlit`
     (файлы из этой папки извлеките из неё так, чтобы в репо оказался
     файл `.streamlit/config.toml`);
   - **Commit changes**.

2. Подключите Streamlit Cloud:
   - откройте https://share.streamlit.io и войдите через GitHub;
   - **Create app** → выберите репозиторий `mila-dashboard`,
     ветку `main`, файл `app.py` → **Deploy**.

3. Готово — по выдаваемой ссылке (например `mila-dashboard.streamlit.app`)
   откроется дашборд.

## Обновление данных

Редактируйте Google-таблицу — дашборд сам перечитает её (проверка
каждые 15 секунд, пока страница открыта). Публиковать файл заново
не нужно. Важно: в Google Sheets доступ файла должен быть
«Все, у кого есть ссылка → Просмотр» (это уже настроено).

## Защита кодом (необязательно)

Чтобы дашборд требовал пароль, в Streamlit Cloud зайдите в
**Settings → Secrets** и добавьте:

```toml
mila_pin = "придумайте_пароль"
```

Пока пароль не введён, данные не показываются.

## Другой источник данных

По умолчанию используется фиксированный ID таблицы. При желании
укажите другой адрес через секрет `MILA_SHEET_URL` (полный адрес
экспорта `https://docs.google.com/spreadsheets/export?format=xlsx&id=...`).

## Локальный запуск (для проверки)

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Важно о конфиденциальности

На бесплатном Streamlit Cloud приложение **публичное** — по ссылке
кто угодно увидит суммы и сотрудников. Если это нежелательно:
включите пароль (см. выше) или выберите хостинг с закрытым доступом
(например приватный Hugging Face Space).
